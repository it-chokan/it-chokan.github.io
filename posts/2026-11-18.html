注意

Appleのサービスで大規模障害、iCloudのサインインやApp Storeが一時使えず

日本時間18日の未明から、Appleのサービスで大規模障害が起きました。写真などを預けるiCloudへのサインインや、App Store、Apple Musicが使いにくくなりました。5:30時点で多くは復旧しましたが、一部はまだ止まっています。

原因はAppleの社内の更新で、攻撃ではないとしています。日本での影響は発表されていません。

たとえると本部がレジのシステムを更新したら、全店のレジが一斉に止まったような状態です。

発生
米東部時間11/17の昼ごろから（日本時間11/18の1〜3時台）
影響
iCloudのサインイン、App Store、Apple Music、AppleCare on Device、iCloudメールなど。Apple Payの不具合報告も
原因
Appleの社内の更新（サイバー攻撃ではない）
状況
5:30時点で多くが復旧。AppleCare on Deviceなど一部は未復旧

やること利用者: 「アカウントを確認して」というメールやSMSのリンクは押さない。障害に便乗した偽メールが出回りやすいためです。

楽天証券で最大1125万口座など、個人情報の漏えい公表まとめ（2件）

最大はネット証券の楽天証券で、最大1125万口座のログインIDなどが漏えいした恐れがあります。うち447万口座は年収や資産の情報も含みます。2件とも、テスト環境や外部ツールが入口です。

  • 楽天証券（ネット証券）最大1125万口座ログインID・顧客コード。うち447万口座は氏名・住所・電話・勤務先・出金先口座・年収・資産も。パスワードは漏れていないとしている。入口はテスト環境
  • 東京都の事業「鮨 東京Sushi TOKYO-」（すし作り体験）97件予約者の氏名・メール・電話・国籍・アレルギー情報。予約サービスの委託先が使う外部の分析ツールに不正アクセス

たとえると本店の金庫は無事でも、練習用に置いていた写しの束を盗まれたようなものです。

やること利用者: 楽天証券をかたるメール・SMS・電話には応じない。ログインにパスキーを設定する。管理者: テスト環境に本物の顧客データを置いていないか確かめる。

ヤバい

サイト改善ツール「Optimizely」が悪用され、Zoomなど178組織のサイトにマルウェア

サイトの見せ方を試し比べるツールOptimizelyが悪用され、ビデオ会議のZoomや英銀行のHSBCなど、少なくとも178組織のサイトにマルウェアが仕込まれました。日本時間11/16の昼から11/17の朝に見ただけで、カード番号や暗号資産を盗まれた恐れがあります。

攻撃者はOptimizelyの登録手続きの穴を突き、各社のサイトが読み込むスクリプトを書き換えました。スクリプトは暗号資産の送金先を差し替え、カード番号やCookieを盗みます。古いiOSには、エクスプロイトキットも送られました。

たとえると店に置いた業者のチラシ立てに、偽の振込先を書いたチラシを混ぜられたような話です。

期間
11/16 13:21ごろ〜11/17 8:11ごろ（日本時間）
規模
少なくとも178組織（188ファイル）。Zoom、BBC、CNN、HSBC、Salesforce、GitLab、IKEAなど
iPhone
iOS 18.7.3以降、iOS 26.3以降は対策済み。乗っ取りの報告はまだない
対応
Optimizelyは穴をふさぎ、仕込まれたコードを削除

やること利用者: iPhoneとiPadを最新のiOSに更新する。期間中にこれらのサイトでカードを入力した人は、明細を確かめる。管理者: 外部ツールから読み込むスクリプトを洗い出し、勝手に変わったら気づける監視を入れる。

注意

【11/16公表】スパコン「富岳」に不正アクセス、運用停止で最大4597人の情報漏えいの恐れ

国の研究機関理化学研究所が11/16、スーパーコンピューター富岳に不正アクセスがあり、運用を止めたと公表しました。利用者最大4597人の氏名やメールアドレスのほか、研究データや外部につなぐ鍵が漏れた恐れがあります。

攻撃者は、ネットに公開していた稼働状況のダッシュボードから内部に入りました。盗んだ認証情報で、ほかのシステムへの接続も試しています。

たとえると来館者向けの案内掲示板から、研究所の裏口に入られたような話です。

侵入
11/10〜11/13（検知11/12、運用停止11/14）
漏えいの恐れ
富岳の利用者最大4,222人と、AI研究システム「理究」の利用者最大375人の氏名・メール等。ホームディレクトリのSSH秘密鍵・アクセスキー・研究データ
再開
未定（悪用された脆弱性への対処とサーバーの再構築の後）

やること利用者: 富岳に置いていたSSHの鍵やアクセスキーは、つなぎ先のサービス側で無効にして作り直す。管理者: ネットに公開している監視用の画面を洗い出し、不要なら閉じる。

ヤバい

サーバー設定管理ツール「Puppet Enterprise」の穴、米政府が悪用を確認

多数のサーバーの設定を自動でそろえる管理ツールPuppet Enterpriseの穴が、攻撃に使われています。米政府の「悪用確認済みリスト」KEVに11/17に載りました。管理サーバーを乗っ取られる恐れがあるため、使っている会社はすぐ更新が必要です。

細工した報告データを送ると、管理サーバーで任意のコードを動かせます。深刻度はCVSS 9.4で、攻撃コードも公開済みです。

たとえると支店から届く日報に命令書を紛れ込ませ、本社の金庫番を動かすような手口です。

CVE
CVE-2026-115731（CVSS 9.4）
直った版
Puppet Enterprise 2023.8.13 / 2025.12.1 / 2026.0.1、OpenVox Server 8.18.0 / 9.2.0
米政府機関の期限
12/1

やること管理者: Puppet Enterpriseを直った版に更新する。すぐ更新できないなら、管理サーバーへの通信を社内だけに絞る。更新の止まった無料版Open Source Puppetは、後継のOpenVoxへ移す。

注目

Microsoft、自社開発のAIモデル7種を発表 プログラミング用はGitHub Copilotで今日から

Microsoftが11/17、自社開発の新AIモデル7種を発表しました。プログラミング用の「MAI Code 2」と軽量版「MAI Code 2 Flash」は、AIのコード補助サービスGitHub Copilotで今日から選べます。

使えるのは年額プランの契約者で、Flashは無料プランでも選べます。他社の上位AIに近い性能を、低い費用で出すとしています。

たとえるといつもの文房具店に、店のオリジナル文具が並び始めたような話です。

やること利用者: Copilotのモデル選択で試し、今のモデルと速さや仕上がりを比べる。管理者: 新しいモデルは初期設定で自動的に使える状態になる。社内ルールに合わなければ、Copilotの設定で止める。

今日のキーワード

テスト環境：本番のサービスに出す前に、動きを試すための別の環境。本番より守りが甘くなりがちで、本物の顧客データを写して置くと、そこが漏えいの入口になります。今日の楽天証券の件も、テスト環境の情報が外に出た可能性が示されました。試験には架空のデータを使うのが基本です。
